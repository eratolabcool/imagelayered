## What is Image Layered?

Image Layered is a browser Studio for recovering editable structure from a finished image. Upload a JPG, PNG, or WebP, generate semantic transparent layers, inspect the result, and continue the work in Photoshop, Photopea, Live2D, Spine, or After Effects.

The product is built around one workflow:

**Upload → AI layer decomposition → select and lock objects → local edits → export PSD or transparent PNG ZIP.**

## Use it in five steps

1. **Upload an image** in [Studio](/studio). Local upload and arranging a project are free.
2. **Generate layers** with the configured decomposition model. AI operations require a signed-in account and credits.
3. **Inspect the layer stack.** Names such as Background, Main Subject, Product, Text / Graphics, Shadow, and Lighting / Effects help you find the part you need.
4. **Lock and edit.** Lock layers that must stay unchanged, hide or move a layer, or run a focused edit on the selected object.
5. **Export the deliverable.** Download a multi-layer raster PSD or a ZIP of transparent PNGs.

## What the PSD contains

The PSD export preserves raster layers, transparency, visibility, order, opacity, groups, masks, and supported blend modes. It does not reconstruct native fonts, vectors, smart objects, or complete edit history. Text from a flattened image remains an image layer, so check spelling and edges before delivery.

## What Image Layered is not

It is not a single-object background remover, a vectorization tool, or a one-click Live2D model generator. Character slicing and parallax preparation are useful workflows built on top of the layer output; rigging, mesh creation, and animation still happen in your target application.

## Choosing the right starting point

- [Image to Layers](/image-to-layers) for products, people, logos, and AI artwork.
- [Poster to PSD](/poster-to-psd) for campaign graphics and text-heavy compositions.
- [AI Image Editing](/ai-image-editing) when you need to change one object while protecting the rest.
- [Image to PSD](/image-to-psd) when the deliverable is a Photoshop file.

## Credits and failures

One decomposition currently costs 5 credits. Selected-layer AI edits cost 3–4 credits depending on the operation. Failed provider tasks are refunded; exporting a completed project does not consume credits. If a task cannot run, Studio reports whether the provider is not configured, credits are exhausted, or the source image is difficult to decompose.

The decomposition engine can change over time. Users do not need to install a model or visit an external inference platform to use Image Layered.
